# 슬랙 문의 자동화 에이전트 버그 수정

**날짜:** 2026-04-16  
**작업자:** 이주민 팀장  
**저장소:** ddome7/LJM_Test

---

## 발생 문제

- 테스트 1건 정상 처리 확인
- 3/30 과거 메시지에 달린 이모지까지 감지되어 메일 초안 2개 생성됨
- 신규 메시지만 처리해야 하는데 과거 이력까지 반응

## 원인

`fetch_triggered_messages()` 함수에서 `conversations_history(limit=20)`만 사용  
→ 날짜 필터 없이 채널 내 최근 20개 메시지를 전부 조회  
→ 3/30 메시지가 20개 안에 포함 + 이모지 달려 있어 처리됨

## 수정 내역

**파일:** `agents/slack-inquiry-agent/main.py`

- 에이전트 시작 시점(`agent_start_ts = str(time.time())`)을 기록
- `conversations_history(oldest=agent_start_ts)` 파라미터 추가
- 에이전트 실행 이후 신규 등록 메시지만 조회하도록 제한
- `processed_ts.json` 초기화 (과거 기록 불필요)
