- **Primitive:** `runWorkflowCForClient(companyName, deps): Promise<WorkflowCResult>` — 단일 client에 대해 19단계 파이프라인 수행 (D-05 모드 B)

설계 원칙:
1. **Primitive-first** — runWorkflowC는 runWorkflowCForClient의 얇은 래퍼. 코드 중복 0.
2. **DI 원칙** — AI 호출 2종(`generateCadenceFollowUpBody`, `classifyContextWithAI`)과 사용자 대화(`askCeoDormantConfirmation`)는 optional DI. 주입 없으면 deterministic / placeholder / draft-only 모드로 동작 (Claude Code 모드 호환).
3. **안전 3중 게이트 복제** — Phase 2의 cross-contamination → prices → quality 순서를 그대로 재적용. 추가로 **Phase 4 신규 금기 표현 게이트**를 compose 이전에 삽입.
4. **Pitfall 4 subject 덮어쓰기** — composeEmail 결과의 subject를 `buildCadenceFollowUpSubject(threadHistory, client, stage)`로 교체한 후 createDraft 호출. Phase 3 패턴 복제.
5. **per-iteration try-catch** — runWorkflowC 루프는 한 client 실패가 batch 전체를 중단시키지 않도록 각 iteration을 감싼다. workflow-b의 패턴 그대로.
6. **D-01 재확인** — 파일 어디에도 주기 실행 API 단어(cron/timer/scheduler) 금지. 우회 표현 "on-demand" 또는 "주기 실행 API(금지)" 사용.

```typescript
    'persona',
    'email-rules-kr',
    'subject-format',
    'tone-calibration',
    'followup-cadence',  // 04-03에서 등록한 §15

  if (classification.language !== 'korean') sections.push('email-rules-en');

  if (classification.hasObjection) sections.push('objection-handling');

}
```

    ```typescript
    export async function runWorkflowC(
      deps: WorkflowCDependencies,
      options: { maxDrafts?: number; companyName?: string } = {},
    ): Promise<WorkflowCBatchResult | WorkflowCResult> {
      if (options.companyName) {
        return runWorkflowCForClient(options.companyName, deps);
      }
      const maxDrafts = options.maxDrafts ?? 10;
      const activeClients = deps.clientQueries.getActiveFollowupClients();
      // getActiveFollowupClients는 이미 lastContactDate asc 정렬이지만, 안전하게 재정렬
      activeClients.sort((a, b) => {
        const A = a.lastContactDate ?? '';
        const B = b.lastContactDate ?? '';
        return A.localeCompare(B);
      });

      const batch: WorkflowCBatchResult = {
        processed: 0, drafted: 0, skipped: 0, errors: 0,
        rows: [], pendingBeyondCap: 0, dormantCandidates: [],
      };

      for (const client of activeClients) {
        if (batch.drafted >= maxDrafts) {
          batch.pendingBeyondCap++;
          continue;
        }
        try {
          const result = await runWorkflowCForClient(client.companyName, deps);
          batch.processed++;
          const row = buildReportRow(client, result);  // 내부 헬퍼
          batch.rows.push(row);
          if (result.status === 'success') {
            batch.drafted++;
            if (result.dormantPending) {
              batch.dormantCandidates.push({ companyName: client.companyName, draftId: result.draftId });
            }
          } else if (result.status === 'no_action') {
            batch.skipped++;
          } else {
            batch.errors++;
          }
        } catch (err) {
          batch.errors++;
          batch.rows.push({
            companyName: client.companyName,
            lastOutboundAt: client.lastContactDate ?? null,
            elapsedDays: null, nextCadence: null, draftId: null,
            status: 'error',
            note: err instanceof Error ? err.message : String(err),
          });
        }
      }
      return batch;
    }
    ```
