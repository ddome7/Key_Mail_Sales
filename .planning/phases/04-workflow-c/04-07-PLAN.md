## Claude Code 세션 필수
이 스크립트는 Node tsx 단독으로 돌면 Gmail MCP에 접근할 수 없다. 반드시 **Claude Code 세션이 직접 스크립트를 실행하거나, Claude Code 세션 내부에서 runWorkflowCForClient를 직접 호출**해야 Gmail 도구가 주입 가능하다. Phase 3 03-UAT.md의 "Claude Code 세션 컨텍스트 필수" 결론과 동일.

실행 모드는 아래 둘 중 하나:
- **A) 스크립트 실행:** Claude Code 세션이 Bash 도구로 `npx tsx scripts/_uat-workflow-c-dryrun.ts` 호출. Gmail MCP 도구 참조를 script 내부에서 어떻게 얻을지는 Phase 3 UAT 스크립트 패턴 확인 (03-UAT.md에 선례 있음).
- **B) 인라인 호출:** Claude Code 세션이 스크립트 없이 직접 runWorkflowCForClient 호출 + 필요한 DI를 MCP 도구로 wrap. 이 경우 _uat 스크립트는 "조립 로직 문서화" 역할.

→ **권장: A 모드**. 03-UAT.md에서 이미 A 모드가 검증되었다면 패턴 그대로.
