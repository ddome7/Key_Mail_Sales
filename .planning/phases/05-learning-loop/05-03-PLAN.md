    ```typescript
    export function stripHtmlForComparison(html: string): string {
      return html
        .replace(/<br\s*\/?>/gi, '\n')
        .replace(/<\/p>/gi, '\n\n')
        .replace(/<[^>]*>/g, '')
        .replace(/&nbsp;/g, ' ')
        .replace(/&amp;/g, '&')
        .replace(/&lt;/g, '<')
        .replace(/&gt;/g, '>')
        // 서명 블록 스트립 (RESEARCH Pitfall 2)
        // "---" 또는 "- -" 또는 "Best regards" 이후 모든 내용 제거
        .replace(/\n\s*---[\s\S]*$/m, '')
        .replace(/\n\s*Best regards[\s\S]*$/mi, '')
        .replace(/\n\s*감사합니다[\s\S]*$/m, '')
        .trim();
    }
    ```

    **주의:** 서명 스트립 패턴은 완벽하지 않을 수 있으나, AI 요약 방식을 사용하므로 (RESEARCH §3) 서명 차이가 남아도 AI가 "서명 관련 변경"으로 분류하면 의미 있는 수정이 아님을 판별할 수 있다.
