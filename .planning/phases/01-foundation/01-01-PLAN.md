## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| User input -> DB query | 클라이언트명/서비스명 입력이 SQL 쿼리로 전달 |
| DB data -> Email content | DB에서 조회한 데이터가 이메일 본문에 삽입 |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-01 | Tampering | SQL queries | mitigate | Drizzle ORM parameterized queries 사용 -- raw SQL interpolation 금지. eq() 함수로 조건 전달 |
| T-01-02 | Information Disclosure | client queries | mitigate | getAllClients 함수 미생성. 모든 쿼리가 단일 클라이언트만 반환 (D-04) |
| T-01-03 | Tampering | seed data | accept | 시드 데이터는 개발자가 수동 입력. v4 ULTRA 원본과 대조하여 정확성 확인 |
</threat_model>
