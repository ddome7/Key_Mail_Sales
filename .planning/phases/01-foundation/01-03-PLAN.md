1. src/state/pipeline.ts 생성 (per D-07):

Zod 스키마 정의:
```typescript
import { z } from 'zod';

const StageEnum = z.enum(['PROSPECT', 'LEAD', 'CLIENT', 'RETENTION', 'DORMANT']);

const DealSchema = z.object({
  id: z.string(),                      // UUID 또는 slug (예: "ohareum-beauty")
  companyName: z.string(),
  contactName: z.string().optional(),
  stage: StageEnum,
  lastActionDate: z.string(),          // YYYY-MM-DD
  nextActionDate: z.string().optional(),
  nextActionType: z.string().optional(), // "follow-up-email", "call", "meeting" 등
  emailThreadId: z.string().optional(),
  notes: z.string().optional(),
});

const PipelineSchema = z.object({
  version: z.literal(1),
  lastUpdated: z.string(),             // ISO 8601
  deals: z.array(DealSchema),
});
```

CRUD 함수:
- `loadPipeline(): Pipeline` -- state/pipeline.json 읽기 + Zod 검증. 파일 없으면 빈 파이프라인 반환.
- `savePipeline(pipeline: Pipeline): void` -- 원자적 쓰기 (임시 파일에 쓴 후 rename). Zod로 저장 전 검증.
- `addDeal(deal: Omit<Deal, 'id'>): Deal` -- UUID 생성, deals 배열에 추가, 저장
- `updateDealStage(dealId: string, newStage: Stage): Deal` -- 특정 딜의 stage 변경, lastActionDate를 오늘로 갱신
- `getDeal(dealId: string): Deal | undefined` -- ID로 딜 조회
- `getDealByCompany(companyName: string): Deal | undefined` -- 회사명으로 딜 조회

원자적 쓰기 패턴 (Pitfall 5 대응):
```typescript
import { writeFileSync, renameSync } from 'fs';

function atomicWrite(filePath: string, data: string): void {
  const tmpPath = filePath + '.tmp';
  writeFileSync(tmpPath, data, 'utf-8');
  renameSync(tmpPath, filePath);  // atomic on most filesystems
}
```
