====================================================
  슬랙 문의 자동화 에이전트 - Windows 서비스 사용법
====================================================

[ 한 줄 요약 ]
install_service.bat 을 "관리자 권한으로 실행"하면 끝입니다.
이후 PC를 켜면 자동으로 백그라운드에서 실행됩니다.


[ 처음 설치할 때 ]
1) 이 폴더의 install_service.bat 파일을 "우클릭"
2) "관리자 권한으로 실행" 클릭
3) 설치가 진행됩니다 (NSSM 자동 다운로드 → 서비스 등록 → 실행)
4) "설치 완료!" 메시지가 나오면 끝


[ 동작 방식 ]
- Windows 서비스로 등록되어 PC 부팅 시 자동 시작됩니다.
  (로그인 전에도 실행됨)
- 창이 뜨지 않고 백그라운드에서만 동작합니다.
- 프로세스가 어떤 이유로든 죽으면 3초 뒤 자동 재시작됩니다.
- 로그는 logs 폴더에 자동 저장되며 매일/10MB 단위로 로테이션됩니다.


[ 자주 쓰는 명령 (모두 "관리자 권한으로 실행") ]
 - install_service.bat    → 최초 설치 (또는 재설치)
 - uninstall_service.bat  → 서비스 제거
 - restart_service.bat    → 서비스 재시작
 - status_service.bat     → 상태 확인 + 최근 로그 보기


[ 로그 위치 ]
 - logs\agent_stdout.log   → 정상 로그
 - logs\agent_stderr.log   → 에러 로그


[ 수동으로 잠시 멈추고 싶을 때 ]
 1) 윈도우 키 → "서비스" 검색 → "서비스" 앱 실행
 2) "Slack Inquiry Agent (퍼즐)" 찾기
 3) 우클릭 → 중지 / 시작 / 다시 시작


[ 문제 해결 ]
 - 설치가 실패하면 관리자 권한으로 실행했는지 먼저 확인
 - NSSM 다운로드 실패 시:
   https://nssm.cc/download 에서 수동 다운로드 →
   nssm-2.24\win64\nssm.exe 를 이 폴더의 nssm\nssm.exe 로 복사
 - 실행이 되는데 메일이 안 오면 logs\agent_stderr.log 확인


[ 제거하고 싶을 때 ]
 1) uninstall_service.bat 을 관리자 권한으로 실행
 2) 끝 (nssm 폴더와 logs 폴더는 수동으로 삭제)
