# 퍼즐코퍼레이션 세일즈 메일 스타일 가이드

> AI가 메일 초안을 작성할 때 반드시 참고해야 하는 내부 기준 문서입니다.

---

## 1. 인사말 패턴

### 기본 구조
```
안녕하세요 :) [회사명] [담당자명]님
퍼즐코퍼레이션 [발신자 이름]입니다.
```

### 실제 예시

**신규 문의 자동 응답형**
```
안녕하세요 :) (주)브리드케어 김선정님
그로스 마케팅 에이전시 퍼즐코퍼레이션 입니다.
```

**담당자가 직접 보내는 영업/협업 메일형**
```
안녕하세요 :) 넥스트웍스 김희연 팀장님
퍼즐 안태언 입니다
```
```
안녕하세요, 김석희 그룹장님.
퍼즐코퍼레이션 최영민입니다. 반갑습니다.
```

### 인사말 규칙
- 이모티콘 `:)` 을 인사말에 **반드시** 포함 (브랜드 시그니처)
- 회사명 + 담당자 이름 + 직함(팀장/그룹장 등) 순서로 호칭
- 자동화 메일은 `퍼즐코퍼레이션 입니다` / 개인 발신 메일은 `퍼즐 [이름]입니다` 또는 `퍼즐코퍼레이션 [이름]입니다` 두 가지 모두 사용 가능
- 쉼표(,) 사용 여부는 문맥에 따라 유연하게 적용 (딱딱하지 않게)

## 2. 본문 구조 패턴

### 유형 A: 문의 접수 확인 메일 (자동화)
```
[인사말]
문의를 남겨주셔서 진심으로 감사드립니다.
[다음 단계 안내 또는 담당자 연락 예고]
```

### 유형 B: 자료 열람 감사 메일 (자동화)
```
[인사말]
퍼즐코퍼레이션의 [회사소개서 / 콘텐츠 상품소개서]가 현재 갖고 계신 [문제/니즈]에 도움이 되셨으면 합니다.
[제안 또는 미팅 제안]
```

### 유형 C: 영업 제안 메일 (담당자 직접 발송)
```
[인사말]
[현황 공유 or 접근 맥락 — 1~2문장으로 간결하게]

---
[핵심 제안 내용]
[데이터/근거 제시]
[협업 가능 영역 제안]
[다음 액션 제안 (미팅 등)]
```

**실제 예시 (최영민, 리코 업박스 제안)**
```
용건 먼저 드리면, [어필리에이트 파트너십 구조]를 함께 제안 드리고자 연락드렸습니다.
그 전에, 팀원분들과 이야기 나누면서 퍼포먼스 마케팅 지표도 함께 살펴봤습니다.

---
올해 1월부터 현재까지 약 6천만원 집행 기준으로, 견적 전환당 비용이 약 17만원 수준이더라고요.
```

### 유형 D: 유선 미팅 후 내용 정리 메일
```
[인사말]
우선 저희 퍼즐코퍼레이션에 문의주셔서 감사말씀드리며,
유선으로 문의주셨던 내용에 대해 아래 전달 드립니다!

✅ 유선미팅 내용
- 상황
  - [내용]
- 내부 니즈
  - [내용]
- 채널 현황
  - [내용]
```

### 유형 E: 짧은 회신 메일
```
[인사말]
[한 줄 확인/동의 표현]
[다음 단계 안내]
[마무리]
```

## 3. 자주 쓰는 표현 및 문구

### 감사 표현
| 상황 | 표현 |
|------|------|
| 문의 접수 시 | `문의를 남겨주셔서 진심으로 감사드립니다.` |
| 자료 열람 시 | `퍼즐에 관심을 가져주셔서 감사합니다!` |
| 회신 받았을 때 | `바쁘신 와중에도 회신 주셔서 감사합니다!` |
| 확인/처리 완료 시 | `확인해주셔서 감사드리며` |

### 제안/전달 표현
- `아래 전달 드립니다!`
- `용건 먼저 드리면,`
- `~에 대해 아래 전달 드립니다!`
- `~하면 좋을 것 같습니다`
- `~해드릴 수 있습니다`
- `~을 함께 제안 드리고자 연락드렸습니다.`

### 일정 조율 표현
- `[날짜] 혹은 [날짜]는 일정이 없어서 그때 편하신 일정 주시면 제가 맞춰보겠습니다! :)`
- `편하게 의견 주세요!!`
- `오전 시간대도 정해주시고 제가 맞춰서 방문 드릴 수 있게 할게요!`
- `차주 화요일에 한번 더 리마인드 메일을 드리겠습니다.`

### 동의/수락 표현
- `이견없으며`
- `확인하였으며`
- `네, 확인했습니다 :)`
- `문제 없을듯 합니다`
